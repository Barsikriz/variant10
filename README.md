# Эмулятор оболочки ОС — вариант 10

Этап 1: ядро REPL на C. `ls` и `cd` выводят имя и аргументы,
`exit` завершает сеанс. Разбор выполняется по пробелам.
Неизвестная команда и аргументы у `exit` вызывают ошибку.
Настроек на этом этапе нет.

## Функции

- `copy_text`: копирует строку с выделением памяти.
- `message`: формирует ответ и возвращает статус.
- `next_token`: выделяет очередной токен по пробелам.
- `shell_execute`: разбирает и выполняет команду; ответ освобождается через `free`.
- `check_command`: проверяет ответ и статус команды.
- `main` в тестах: запускает проверки.

## Сборка и тесты

В Developer Command Prompt для Visual Studio с компонентами C++ и Windows SDK:

```bat
run.bat
```

## Примеры

`ls -l /home` возвращает `ls -l /home`, `cd /tmp` возвращает `cd /tmp`.
`unknown` возвращает сообщение о неизвестной команде.
